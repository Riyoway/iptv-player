# Contributing

Thanks for your interest in IPTV Player.

## Development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Run `npm run dev` while developing.
4. Run `npm test`, `npm run lint`, and `npm run build` before opening a pull request.

## Pull requests

Keep pull requests focused and explain the user-facing change. Avoid committing playlists, credentials, subscription URLs, tokens, generated build output, or copyrighted media.

For UI changes, test both desktop and mobile layouts. For playlist changes, add or update parser tests where practical.

## Issues

When reporting playback issues, do not post private IPTV credentials. Include the browser, operating system, stream format, whether a public test stream reproduces the issue, and any relevant console error with secrets removed.
